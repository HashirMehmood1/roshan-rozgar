APP: "Roshan Rozgar" (روشن روزگار) — voice-first, two-sided web marketplace, Islamabad, Pakistan. Households hire nearby skilled trade workers (electrician, plumber, AC technician, carpenter, mechanic, painter). Workers have LOW LITERACY — no forms, no typing: a worker creates his profile by SPEAKING Urdu, a customer books by speaking, they exchange VOICE NOTES, agree price with big Accept/Reject buttons, and after the job the customer rates with big stars + a spoken review.
STACK (never change): Next.js (JavaScript, App Router, no TypeScript), Tailwind CSS, shadcn/ui (Button, Card, Badge, Input only), lucide-react, Supabase Postgres via @supabase/supabase-js, Gemini API, Web Speech API, MediaRecorder. Deploy Vercel. DESKTOP-FIRST responsive: container max-w-7xl mx-auto px-4; hero 2-column on lg; grids 3-col desktop / 2-col tablet / 1-col mobile; buttons stay min-h 56px and Urdu text sizes never shrink.
5 FLOWS: (1) Voice onboarding: speech → Gemini extracts profile JSON → confirm with icons/chips/stepper → save to Supabase. (2) Discovery: trade tiles OR spoken problem → Gemini detects trade → workers where trade matches AND available=true, same area first, then rating. (3) Communication: voice notes inside a job + worker Accept/Reject on price. (4) Booking: creating a job ALSO sets workers.available=false; completing/rejecting sets it back to true. (5) Trust: reviews only on completed jobs; worker cards show rating, jobs_done, and a one-line Gemini Urdu summary of reviews.
DATABASE (Supabase, RLS disabled, anon key only, never service_role): workers(id, name, trade, area, rate, experience_years, phone, available, rating, jobs_done, created_at); jobs(id, worker_id, customer_name, customer_area, problem, trade, urgency, price_offered, status pending|accepted|rejected|completed, created_at); messages(id, job_id, sender customer|worker, kind, text, audio_url base64, created_at); reviews(id, worker_id, job_id, stars 1-5, comment, customer_name, created_at). Trades: electrician|plumber|ac_technician|carpenter|mechanic|painter. Areas: G-9|F-11|I-8|H-12|G-13|F-7.
AI: Gemini ONLY via server route app/api/ai/route.js, plain fetch, model gemini-2.0-flash, key in GEMINI_API_KEY (never NEXT_PUBLIC_). POST {task, text}: task profile → JSON {name,trade,area,rate,experience_years}; task detect → JSON {trade,urgency,summary}; task summarize → one Urdu line, max 15 words. Strip code fences before JSON.parse. On ANY AI error return {error:true} — the UI must fall back to tap-only and never crash.
VOICE: webkitSpeechRecognition hook (lang ur-PK, fallback en-US); MediaRecorder voice notes max 20s saved as base64 into messages.audio_url; speechSynthesis read-aloud buttons.
LANGUAGES: Urdu script default, Roman Urdu, English. LanguageSwitch pill in header (اردو | Roman | EN), saved in localStorage 'lang', strings in lib/translations.js (ur/roman/en), Urdu sets dir=rtl. Voice language follows the switch.
STYLE: primary orange #FF6B00, hover #E85D00, ink #111111, bg white, section bg cream #FFF7ED, card border #E5E7EB, cards rounded-2xl shadow-sm, buttons rounded-full min-h 56px text 18px+. Fonts: Poppins (English/numbers, prices as "Rs 1,500"), Noto Nastaliq Urdu (Urdu text, line-height 2.2). Green #16A34A only Available/Accept; red #DC2626 only Busy/Reject; amber #F59E0B only stars. Icons 32-40px with Urdu+English labels. Min tap target 56px. One primary action per screen. No popups, no login.
IDENTITY: no auth. localStorage: worker_id, customer_name, customer_area, role.
PAGES (4 only): app/page.js landing (hero with voice search pill + floating worker card, role chooser, trade grid with starting prices, how-it-works 3 steps, trust strip, top workers, worker CTA banner, footer); app/worker/page.js (voice onboarding OR dashboard with availability toggle + my jobs); app/customer/page.js (problem input/trade grid → worker list → Book creates job + flips availability → go to job page); app/job/[id]/page.js (status stepper, voice-note thread, worker Accept/Reject/Complete, customer stars + spoken review + AI trust summary).
